# Synthetic abdominal CT, mid-L3 slices (v1, 10 samples)

Ten synthetic 2D abdominal CT slices at the middle of the L3 vertebra. Each comes with organ labels and two ready-to-simulate sound-speed maps. The slices are synthetic, generated by NVIDIA's MAISI `rflow-ct` model conditioned on real segmentation masks; no real patient images are included. The method is in [`desmond/docs/simulation_pipeline.md`](../../docs/simulation_pipeline.md) and [`phase1_speed_maps.md`](../../docs/phase1_speed_maps.md).

## Files (one folder per sample)

| File | Contents |
| --- | --- |
| `L3_mid_hu.npy` | 512×512 int16 CT in HU (clipped to −1000…1000), 0.781 mm pixels, radiological orientation (anterior up, patient right on the image left) |
| `L3_mid_label.npy` | 512×512 uint8 MAISI organ labels for the same slice (e.g. 1 liver, 5/14 kidneys, 6 aorta, 19 small bowel, 35 L3 vertebra, 62 colon, 104–107 back/psoas muscles, 200 body). Full list: `configs/label_dict.json` in the NV-Generate-CTMR repo |
| `acoustic.npz` | Sound-speed map from the shared `ct_to_speed.py --mapping hybrid --air-as-water` |
| `acoustic_itis.npz` | Corrected map (`desmond/src/speed_map.py`): IT'IS tissue values, contrast agent removed, graded bone, density map included. Recommended |
| `meta.json` | Seed, model commit, source mask file, slice position, spacing |
| `preview.png` | The slice, its labels, and a sagittal view with the slice marked |

`index.csv` lists every sample with its seed, source mask, body area, fat and bone share, and mean body sound speed.

## Use with the shared scripts

Both `.npz` maps work directly with `--ct-speed`:

```bash
D=desmond/data/ct_slices_l3_v1/sample_0001
python 2DRingFDTD.py --ct-speed $D/acoustic_itis.npz --device cuda:0 --no-show --save-figure /tmp/ring.png
python invert_ring.py --ct-speed $D/acoustic_itis.npz --multiscale --device cuda:0 --no-show --save-figure /tmp/fwi.png
python ct_to_speed.py $D/L3_mid_hu.npy --pixel-spacing-mm 0.781 --output /tmp/my_map.npz   # make your own map from HU
```

`--device cuda:0` is needed under torch 2.14. Pass `--save-figure` so the scripts don't overwrite the PNGs in the repository root.

## Caveats

- **Contrast-enhanced CT.** MAISI always produces contrast-enhanced images. `acoustic_itis.npz` removes the contrast bias; `acoustic.npz` does not.
- **Simulator accuracy.** At the shared simulator's default grid, travel times are biased by about +5 to +8 m/s. See `desmond/docs/phase2_numerics.md`.
- **Anatomy and licensing.** Each sample's anatomy follows one real segmentation mask from MAISI's mask database (public datasets such as AMOS and KiTS; the file is in `index.csv`). Check those datasets' licenses and the NVIDIA Open Model License before sharing outside the lab.
- **Regenerating more.** The 3D volumes and simulation traces are not included. This set is reproduced exactly by `python desmond/src/generate_slices.py --mask-source retrieved --num-volumes 10 --base-seed 0`. The mask pool depends on `--num-volumes` and `--base-seed`, so change those to make new samples. `desmond/src/package_slices.py` rebuilds this folder from a run.
